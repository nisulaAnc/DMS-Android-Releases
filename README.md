# DMS - Document Management System

The **DMS (Document Management System)** is a mobile application developed for **ANC Education** to simplify and streamline the management and submission of student documents.

### Android Application

The latest Android APK is available under the **Releases** section of this repository.

**Current Version:** `v1.0`

### Download & Installation

1. Go to the **Releases** section of this repository.
2. Open the latest release.
3. Under **Assets**, download the **DMS APK** file.
4. Open the downloaded APK on your Android device.
5. If prompted, allow your device to install the APK from the application used to download it.
6. Follow the on-screen instructions to complete the installation.

### Important

- This application is currently distributed as an **Android APK**.
- An Android device is required to install and use the application.
- Please always download the APK from the latest GitHub Release.
- Do not download APK files from unofficial sources.
